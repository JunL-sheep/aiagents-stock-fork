## 3. 架构一览：入场决策链路

```
价格命中入场区间
    ↓
  _evaluate_entry_decision(advisors 列表投票)
    ↓
  ┌─ #1 trading_session —— 非交易时段 → 🚫 suppress（开）
  ├─ #2 news_flow       —— 板块danger  → 🚫 suppress（开）
  ├─ #3 trend            —— 趋势向下   → 🚫 suppress（开）
  ├─ #4 volume           —— 缩量上攻   → 🟡 warn（开）
  ├─ #5 position         —— 已浮盈+5% → 🚫 suppress（开）
  ├─ #6 triple_screen    —— 评分<40    → 🚫 suppress（开）
  └─ #7 market_regime    —— 大盘熊市   → 🚫 suppress（开）
    ↓
  未被抑制 → 推钉钉（9 个字段全填上）
    ↓
  止盈/止损 → 永远推（风控纪律，不走 advisor）
```
